# Inventário de Insumos do Projeto

| Arquivo | O que é | Usado pelo sistema em execução? | Onde será usado | Observações |
| :--- | :--- | :--- | :--- | :--- |
| `docs/FSD.md` | Especificação Funcional e Técnica (FSD) definitiva do sistema | Não | Documentação / Guia de Arquitetura | Versão atual e definitiva com arquitetura, DDL, endpoints REST, fluxos e regras de negócio. |
| `docs/DESIGN.md` | Guia de Design System (*Executive Precision*) | Não | Referência visual / Tokens de Design | Define a paleta de cores, tipografia (Plus Jakarta Sans / Inter), elevações, espaçamentos e componentes. |
| `docs/code.html` | Protótipo visual estático em HTML com Tailwind CSS | Não | Referência de layout e UI | Mockup navegável de referência para estruturação visual das telas e componentes React. |
| `docs/screen.png` | Screenshot / Captura visual do protótipo do painel financeiro | Não | Referência visual | Imagem de apoio para guiar a fidelidade visual e densidade de informação do Dashboard. |
| `assets/logo.png` | Imagem do logotipo oficial do sistema (versão padrão para fundos claros) | Sim | Cabeçalho, barra lateral de navegação e telas de autenticação (Login / Cadastro) | Insumo já disponível na pasta `assets/` da raiz do projeto. |
| `assets/logo_branca.png` | Imagem do logotipo oficial do sistema (versão monocromática branca para fundos escuros) | Sim | Áreas de alto contraste, modais com fundo escuro ou cabeçalhos escuros se aplicável | Insumo já disponível na pasta `assets/` da raiz do projeto. |
